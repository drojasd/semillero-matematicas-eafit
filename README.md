# Semillero de Investigación en Matemáticas · Universidad EAFIT

Sitio y material abierto del Semillero de Matemáticas de EAFIT, que reúne las líneas de
**Matemáticas Puras** y **Biomatemáticas**.

- **Cuándo:** jueves de 3:00 a 5:00 p.m.
- **Dónde:** aula 20-520
- **Requisitos:** ninguno

## Contenido

```
index.html                       página principal
data/sitio.js                    horario, cronograma, líneas de investigación, documentos
assets/                          estilos, script y la invitación del semestre
cursos/introduccion-edo/         notas de introducción a ecuaciones diferenciales
cursos/Nivel 1 diferencial/      notas del Nivel 1 (LaTeX)
cursos/Modelado epidemiológico/  material de las sesiones de modelado con GSUA-CSB
```

Para verlo localmente, sirve la carpeta con cualquier servidor estático, por ejemplo
`python -m http.server`, y abre `http://localhost:8000`.

> Este repositorio se genera automáticamente desde el repositorio interno del semillero.
> Los cambios se hacen allá, no aquí.
